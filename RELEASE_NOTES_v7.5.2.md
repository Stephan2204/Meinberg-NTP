# v7.5.2

Packaging fix only; NTP and security behavior are unchanged.

v7.5.1 relied on `flasher_args.json` being generated by the PlatformIO ESP-IDF
build. On the tested PlatformIO setup this file was not present during a normal
build, so only the OTA image was copied.

v7.5.2 builds the merged factory image from PlatformIO's `FLASH_EXTRA_IMAGES`
plus the application at `ESP32_APP_OFFSET`. It then creates the ESP Web Tools
`manifest.json`.
